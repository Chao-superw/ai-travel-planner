# 行迹 Wandr · 前端

React + TypeScript + Vite，连接 `../BE` 的 HTTP 网关。当前登录使用邮箱和密码，注册需完成邮箱验证码验证。

## 本地运行

后端先启动在 `http://127.0.0.1:8080`，然后在 `FE/` 执行：

```sh
npm ci # 首次安装依赖
npm run dev -- --host 127.0.0.1
```

访问 `http://127.0.0.1:5173`。需要修改接口地址时配置 `VITE_API_BASE_URL`，参考 `.env.example`。SMTP、数据库和模型密钥只由后端读取，不放入 `VITE_*` 配置。

首次配置时将 `.env.example` 复制为 `.env.local`（已有文件时保留原配置），把 `REPLACE_WITH_SHARED_AMAP_KEY` 换成与后端 `AMAP_API_KEY` 相同的值。该项目保留共用 Key；`VITE_AMAP_KEY` 会进入浏览器代码及地图请求，不视为浏览器端秘密。`.env.local`、`.local/`、`dist/` 均不上传到 GitHub，详见[上传脱敏报告](../UPLOAD_GUIDE.md)。

## 邮箱认证

- `/login`：邮箱密码登录。按用户要求，只展示邮箱登录与注册，不展示用户名登录或旧账号迁移入口。
- `/register`：邮箱、密码、确认密码、6 位验证码。先申请验证码，提交成功后转到登录页并填好邮箱；密码与验证码不持久化。
- 发码与验证请求都不会自动重试。重发倒计时采用服务端 `retry_after`；验证码过期后禁止提交，修改邮箱会清除原证明。重发失败时先前仍有效的证明可以继续使用。
- 注册和登录检查密码的 UTF-8 字节长度（8–72），保留邮箱本地部分的大小写，只规范化域名。
- `/bind-email` 是已有未验证会话的补全页，进入业务页面前通过 `/me` 检查。普通登录页没有该流程入口。
- 登录切换账号、退出时清理账号查询缓存，`/me` 按会话隔离；503/504 不把现有会话误判为失效。

完整请求结构、状态码和调用示例见 [后端前端接入指南](../BE/docs/frontend-integration.md) 与 [OpenAPI](../BE/docs/openapi.yaml)。
